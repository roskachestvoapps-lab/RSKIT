# Инструкция по развертыванию приложения ФГИС ФСА

Это приложение предназначено для автоматического парсинга реестра ФГИС ФСА, проверки просроченных сертификатов, автообновления токена авторизации через Playwright и рассылки отчетов на почту.

---

## Вариант 1. Запуск на локальном компьютере (Mac/Windows)
Ваш домашний/офисный IP-адрес не заблокирован серверами ФСА, поэтому локально приложение работает напрямую без прокси и VPN.

1. **Активируйте виртуальное окружение**:
   ```bash
   source .venv/bin/activate
   ```
2. **Запустите Streamlit**:
   ```bash
   streamlit run app.py
   ```
3. Приложение автоматически откроется в браузере по адресу `http://localhost:8501`.

---

## Вариант 2. Запуск в облаке Streamlit Cloud (24/7 автономно)
Так как сервера Streamlit Cloud заблокированы брандмауэром ФСА, приложение использует встроенный фоновый клиент **Xray (VLESS Reality)** для маршрутизации трафика через российский сервер.

### Шаг 1. Отправка обновлений в ваш репозиторий
Выполните команды в терминале:
```bash
git add .
git commit -m "Configure dependencies and Xray proxy support"
git push
```
